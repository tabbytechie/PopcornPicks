# PostGIS

Geospatial extension for PostgreSQL.

## Purpose

- Geospatial data types (geometry, geography)
- Distance calculations
- Radius search
- Bounding boxes
- Polygon search
- Nearest neighbours
- Cinema locations, country data, city data

## Usage

- `geometry` / `geography` data types
- `ST_Distance`, `ST_DWithin`, `ST_Contains`, `ST_Intersects`
- GiST indexes for spatial queries
