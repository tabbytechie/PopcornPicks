# Shared Modules

Reusable types, helpers, common functions, utilities, and constants shared across all domains and platform modules.

## Contents

- `types/` — shared PostgreSQL types (ENUMs, DOMAINs, composite types)
- `helpers/` — common helper functions
- `common_functions/` — widely used SQL functions
- `utilities/` — utility functions and operators
- `constants/` — shared constants and lookup values
